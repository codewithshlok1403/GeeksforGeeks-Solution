This repository contains my **GeeksforGeeks (GFG) solutions written in Java**, created as part of my journey to strengthen Data Structures & Algorithms through consistent practice.

I'm using this repository to improve my logical thinking, understand different problem-solving approaches and learn how to write clean, efficient and optimized code.

- 🧩 Different approaches to DSA problems.

- 📚 Topic-wise problem organization.
