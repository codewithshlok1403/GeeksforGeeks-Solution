## 📈 My Problem-Solving Approach

For every problem, I try to follow this process:

```text
Understand the Problem
        ↓
Think of Brute Force
        ↓
Analyze Time & Space Complexity
        ↓
Find an Optimized Approach
        ↓
Implement in Java
        ↓
Test Edge Cases
        ↓
Improve & Learn
```

The focus is on **understanding the approach rather than simply memorizing the solution**.
